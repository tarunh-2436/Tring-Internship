# Tring Internship Projects

This repository contains all projects completed during my Internship at TringApps.

## Branches

- week-1 — AWS Terraform Portfolio static website hosting on S3 and served using CloudFront
- week-2 — Serverless Feedback API using Lambda API Handling and S3 JSON Object storage
- week-3 — Serverless Feedback API using DynamoDB metadata storage and S3 attachment storage
- week-4 — Serverless Image Processing API using DynamoDB using Event-Driven Architecture through SQS/SNS
- week-5 — Serverless Image Processing Platform using RDS, Redis Caching and CI/CD Pipeline
- week-6 — KnowledgeHub Capstone

Each branch contains the complete source code, documentation, and Terraform configuration for the corresponding week's project.
